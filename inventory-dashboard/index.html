Silent install (admin-approved files)

Upload an installer or executable once here, then push it to agents as a job. It runs with no UI, in the background, using each platform's standard unattended-install switches. Only upload files you trust - everything here runs with the agent service account's permissions.

Defaults used if a job doesn't override them. Windows .exe defaults to /S, .msi to /quiet /norestart if left blank; .deb/.rpm/.pkg/.sh run with no extra args unless you set them.
Allowed types: .exe, .msi, .msp (Windows), .pkg, .dmg (macOS), .deb, .rpm, .run, .sh (Linux). Up to 1 GiB.
